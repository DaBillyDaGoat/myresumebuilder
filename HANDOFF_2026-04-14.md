## One Pending Item: Email Delivery

Email is currently **disabled** for all users (env var `NEXT_PUBLIC_EMAIL_ENABLED=false`).  
Users see a friendly amber notice: *"Email delivery — coming soon. Use Download PDF for now."*

**Root cause:** `myresumebuilder.org` DNS is managed by **MarkMonitor** (enterprise registrar). No self-service portal — requires logging into a MarkMonitor account to change records or nameservers.

### Option A — Easiest: Move DNS to Cloudflare (recommended)
1. Log into your MarkMonitor account
2. Change nameservers to Cloudflare's (free at cloudflare.com):
   - `maya.ns.cloudflare.com`
   - `rick.ns.cloudflare.com`
3. In Cloudflare dashboard, add the domain and add these DNS records for Resend:

| Type | Name | Value |
|------|------|-------|
| TXT | `@` | `v=spf1 include:amazonses.com ~all` |
| CNAME | `resend._domainkey` | *(get from Resend dashboard → Domains → Add Domain)* |
| TXT | `_dmarc` | `v=DMARC1; p=none;` |

4. In Resend dashboard: add domain `myresumebuilder.org`, click Verify
5. Update Vercel env vars:
   - Set `RESEND_FROM_EMAIL` = `noreply@myresumebuilder.org`
   - Set `NEXT_PUBLIC_EMAIL_ENABLED` = `true`

### Option B — Use a different domain you already control
If you have another domain on Namecheap / GoDaddy / Cloudflare, add it to Resend instead. Email doesn't have to come from `myresumebuilder.org`. Even `mail.yourdomain.com` works. Same DNS records as above, then flip `NEXT_PUBLIC_EMAIL_ENABLED=true`.
